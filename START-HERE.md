# Toufic Abou Ali: Six Continents Partner Experience

This is the complete editable source for Toufic Abou Ali's mission, partner brief, race proof archive, founder story, Warsaw case study, and media page.

## Main pages

- `/partners` is the conversion focused partner deck for cold and warm outreach.
- `/proof` is the searchable race and evidence archive.
- `/mission` explains the six race world record attempt and route.
- `/founder` connects the athletic mission to Toufic's work as Founder and CEO of Sira.
- `/warsaw` documents the first IRONMAN 70.3 finish.
- `/media` contains approved facts, biographies, and source material.

## Run locally

Requirements: Node.js 22.13 or newer and npm.

```bash
npm ci
npm run dev
```

## Verify the production build

```bash
npm test
```
