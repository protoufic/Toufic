# Six Continents — Toufic Abou Ali

**6 Continents. 6 Full IRONMAN Races. 1 World-Record Attempt.**

## Quick Start

```bash
cd six-continents
python3 -m http.server 8000
# Open http://localhost:8000
```

## Deploy to Vercel

1. Push to GitHub
2. Import at vercel.com/new
3. Framework: **Other**
4. Deploy
